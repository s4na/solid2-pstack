# 通知設定

## できること

通知のオン・オフを切り替える。リセットするとオフになる。初回表示はオフ。

## 画面の開き方

アプリのルートを開く。Storybook では Settings / Notifications の Off と On を選ぶ。

## ブラウザでの操作

1. Tab で「通知を受け取る」にフォーカスし、Space を押す。
2. 「通知はオンです」と表示され、トグルの `aria-pressed` が `true` になることを確認する。
3. Tab で「リセット」にフォーカスし、Enter を押す。
4. 「通知はオフです」と表示され、`aria-pressed` が `false` になることを確認する。

## 検証範囲

設定はページ内の状態。TLA+ モデルはトグルとリセットの入力・出力の組を扱う。実際のフォーカスと表示はブラウザテストが扱う。

# よりみち商店街

## できること

出店者が店を開いて商品を公開し、購入者が複数店舗の商品をカートでまとめて注文する。注文後、購入者は履歴を、出店者は自分の店の受注と残在庫を確認できる。

## 画面の開き方

README の手順でフロントエンドをビルドし、Docker Compose で Go を起動する。既定の URL は `http://127.0.0.1:8088`。`/api/health` が `{"status":"ok"}` を返すことを確認する。

## ブラウザでの操作

1. 「出店者ページ」で出店者アカウントを作り、店を開いて商品を登録する。
2. 商品一覧で別の店の商品と一緒に選択し、選択した商品をカートに入れる。さらに商品カードの「＋」を押し、チェックマークに切り替わることと、右下のカートで点数・合計がすぐ更新されることを確認する。
3. カートから購入手続きへ進む。購入者として登録またはログインし、ローカル検証用の宛先で確定する。
4. 注文番号、商品、数量、合計を購入者の注文履歴で確認する。出店者ページで自店の商品だけが受注に表示され、在庫が注文数量分減っていることを確認する。
5. 作業で起動した Docker Compose サービスを停止する。SQLite のデータボリュームは保持する。

## 検証範囲

`pnpm --dir frontend test:market` は Docker が配信する画面で上記の操作を実行する。注文番号を証跡に残す。注文確定直後に応答が失われるケースも再現し、再読み込み後に同じ注文が表示され、在庫が一度だけ減ることを確認する。Go の `(cd backend && go test -race ./...)` では、在庫不足や価格変更時のロールバック、同じ注文の再送、同時注文時の在庫競合を確認する。
